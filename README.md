# Personal AI PA

A professional personal AI assistant web application.

## Features

- Custom assistant name
- Custom assistant personality
- Chat interface
- Voice input
- Voice responses
- Personal memories
- Basic assistant commands
- Website opening commands
- Backend API
- Expandable AI architecture
- Future phone and business assistant capabilities
